# Time — by Daniel 'dnyaary' Carvalho

[English](manual.en.md) · [Português](manual.md) · **中文**

> 本文档译自英文版，可能存在不准确之处。如发现错误，欢迎提交 Issue 或 Pull Request 指正。

一款 Windows 程序，用于统计电脑的**真实屏幕使用时间**：只累计有人真正在使用电脑的时间，并按**程序和网站**分别统计。

> 界面语言跟随 Windows（窗口）和手机（仪表盘）的语言：系统为葡萄牙语时显示葡萄牙语，其他语言显示英语。本手册中的按钮和标签按英文界面书写，并附中文含义，例如 **"Start with Windows"**（开机自动启动）。

Time 运行时**不在系统托盘显示图标**。它的小窗口保持隐藏，只能通过全局快捷键打开：

> **按住 Ctrl + Shift + Alt，按 X，然后在 4 秒内按 5。**

同一个快捷键也可以隐藏窗口。要真正退出程序，请点击完整窗口的 **X**（会先保存数据再关闭）。

你也可以在同一 Wi-Fi 网络下用**手机**查看所有数据，无需云端和账号——见[手机仪表盘](#手机仪表盘)。

## 统计内容

- **活动时间：** 只有在容忍时间内有鼠标或键盘操作时才计时。电脑闲置或锁屏时不计时。
- **按程序/网站：** 每一刻的时间记在当时位于最前面的程序（前台窗口）上，并按 `categorias.txt` 中的规则归类。
- **视频和会议：** 容忍时间更长，因此不碰鼠标观看时仍计为屏幕时间。

### 不会做的事

- 不记录按下了哪些键。
- 不截屏，也不录屏。
- 不保存窗口标题——标题只在当时用于与规则比对；文件中只保存类别名称。
- 不统计后台程序（例如在后面播放的音乐），也不统计不在最前面的浏览器标签页。

## 生成的文件（位于 `C:\Program Files\Time`）

| 文件 | 用途 |
|---|---|
| `atividade_diaria.csv` | 每日总时长。可用 Excel 打开（分隔符为 `;`）。 |
| `atividade_diaria.txt` | 同样的内容，排版为对齐文本，可用记事本阅读。 |
| `apps_diario.csv` | 每天每个程序/网站的时长。供 Excel 使用。 |
| `horas_diario.csv` | 每天每个小时（0 到 23）的使用时长。供 Excel 使用。 |
| `categorias.txt` | 统计哪些内容以及如何命名的列表。需要你自己编辑的就是这个文件。 |
| `config.txt` | 手机仪表盘的端口和访问码。 |
| `pcs.txt` | 仪表盘中的其他电脑，每行一台：`名称; 访问码; 电脑名; ip:端口`。 |

路径固定为 `C:\Program Files\Time`。如果文件夹不存在，程序会在首次运行时创建——首次运行时**只会请求一次管理员权限（UAC）**，因为 Windows 不允许在没有管理员权限的情况下写入 `Program Files`。之后程序会自动写入，不再请求任何权限（包括随 Windows 启动时）。

如果你拒绝了 UAC，程序会继续在 `%LocalAppData%\Time` 中运行，并在打开窗口时提示；只需以管理员身份运行一次 `Time.exe` 即可恢复到正确路径。

### `atividade_diaria.csv` 的列

```
Date;User;Machine;First activity;Last activity;Active time;Seconds;Idle limit (s)
2026-10-22;daniel;PC-TI;08:12:40;17:41:05;06:48:12;24492;30
```

日期；用户；电脑；首次活动；最后活动；活动时间；秒数；闲置限制（秒）。

### `apps_diario.csv` 的列

```
Date;User;Machine;Item;Time;Seconds
2026-10-22;daniel;PC-TI;CorelDRAW;03:12:40;11560
```

日期；用户；电脑；项目；时间；秒数。

### `horas_diario.csv` 的列

```
Date;User;Machine;Hour;Seconds
2026-10-22;daniel;PC-TI;14;3240
```

日期；用户；电脑；小时；秒数。每个有使用的小时一行（`14` = 14:00 到 14:59）。Windows 为葡萄牙语时，列名为葡萄牙语。

## `categorias.txt` 规则列表

每行一条规则，格式为：

```
类型: 文本 = 显示名称 | 容忍时间
```

**类型：**

- `site:`（网站）——在标签页标题中查找文本，**仅当窗口是浏览器时**生效（Chrome、Edge、Firefox、Opera、Brave、Vivaldi）。
- `title:`（标题）——在**任意**窗口的标题中查找文本。请谨慎使用。
- `program:`（程序）——与进程名称的开头比对，不含 `.exe`（可在任务管理器 → 详细信息中查看名称）。

葡萄牙语关键字（`titulo:` 和 `programa:`）同样有效。

**规则说明：**

- **第一条匹配的规则生效**，因此网站规则要放在浏览器规则之前。所以在 Chrome 中打开的 YouTube 计为 "YouTube"，而不是 "Browser"（浏览器）。
- 不匹配任何规则的内容计入 **"Others"**（其他）。
- **Time** 本身是例外：窗口打开时，它会以 **"Time"** 出现在列表中（无需在 `categorias.txt` 中添加规则）。
- 保存文件后，程序会在几秒内**自动重新加载**，无需重启。

**分组（可选）：**

方括号中的名称单独占一行，会把下面的规则归入该组，直到下一个分组为止。单独一行 `[]` 表示回到"不分组"。仪表盘会在 **"By group"**（按分组）中汇总每个分组的时长。

```
[Social media]
site: Instagram = Instagram
site: TikTok = TikTok | 180

[Work]
program: CorelDRW = CorelDRAW
program: EXCEL = Excel

[]
program: chrome = Browser
```

新建的 `categorias.txt` 已经包含分组（社交媒体、视频和音乐、通讯、AI、工作、购物和游戏）。分组不会写入历史记录：把某个程序移到别的分组后，仪表盘会立刻把它以前的时长计入新分组。

**容忍时间（可选，写在行末）：**

指不碰鼠标/键盘多长时间内仍为该项目计时。不写 `|` 时使用默认的 30 秒。适用于视频和会议，因为观看时通常不会操作电脑。

```
site: YouTube = YouTube | 600      （静止 10 分钟内仍继续计时）
site: TikTok = TikTok | 180        （3 分钟）
program: Zoom = Zoom | 900         （15 分钟）
```

默认设置：视频 10 分钟，短视频 3 分钟，会议 15 分钟，其他一律 30 秒。

**如果某个程序被归入 "Others"：** 打开任务管理器 → 详细信息，查看进程名称，然后添加 `program: 进程名 = 显示名称`。

## 编译与发布

需要 .NET 10 SDK（或 Visual Studio）。在包含 `Program.cs` 和 `Time.csproj` 的文件夹中运行：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

生成的单个可执行文件位于：

```
bin\Release\net10.0-windows\win-x64\publish\Time.exe
```

它是独立文件：可在任何 Windows 电脑上运行，无需安装 .NET。发布前如需快速测试，可在文件夹中运行 `dotnet run`（这种方式直接从所在文件夹运行，不会安装到 `Program Files`）。

同时生成的 `.pdb` 只用于调试；分发时只需提供 `.exe`。

## 在每台电脑上安装

1. 在下载位置运行 `Time.exe`。**屏幕上不会出现任何东西**——它在后台隐藏运行。
2. 首次运行时，它会**把自己复制到 `C:\Program Files\Time\Time.exe`**，此后从那里运行。之后可以删除下载文件夹，程序不再依赖它。
3. Windows 会请求**两次管理员权限（UAC）**：一次用于创建并开放 `C:\Program Files\Time` 文件夹（数据存放处），一次用于开放防火墙。
4. 按快捷键 **Ctrl+Shift+Alt+X，然后按 5** 打开窗口：只显示名称 **Time** 和最小化按钮。
5. 窗口打开时，按 **Ctrl+Shift+Alt+F2，然后按 1** 查看完整信息，并勾选 **"Start with Windows"**（开机自动启动）。

同一个 `Time.exe` 适用于所有电脑——它是单个独立文件，没有安装程序。由于没有数字签名，首次运行时 Windows 可能提示"Windows 已保护你的电脑"：点击**更多信息**，再点击**仍要运行**。通过 WhatsApp 或电子邮件发送 `.exe` 文件常被拦截；请使用 U 盘、网络共享文件夹或云盘链接。

完成首次授权后，程序无需管理员权限即可运行，不会再请求任何权限。如果本机的其他用户已经开放过 `C:\Program Files\Time` 文件夹，甚至不会出现授权提示。

"Start with Windows" 写入的是当前用户自己的注册表项，因此每个用户都需要在自己的账户中勾选一次。由 Windows 自动启动时**不会**请求 UAC（只有手动运行时才会请求）。

**重要：** 程序位于 `C:\Program Files\Time\Time.exe`。如果移动了这个文件，请再次运行它：它会把自己复制回原位置，开机启动项也会重新指向正确位置。更新时，请先通过**完整窗口的 X** 关闭 Time，再运行新的 `.exe`——它会覆盖安装。

## 日常使用

- **快捷键 Ctrl+Shift+Alt+X，然后按 5：** 打开迷你窗口（屏幕右下角）：只显示名称 **Time** 和 **—** 最小化按钮。最小化即重新隐藏；窗口打开时再按同一快捷键也会隐藏。
- **快捷键 Ctrl+Shift+Alt+F2，然后按 1：** 窗口打开时显示完整信息（时间、程序、往日记录、仪表盘链接）。如果没有任何窗口打开，会直接打开完整窗口。第二个按键最多有 **4 秒**时间，按下第一个键后可以松开 Ctrl/Shift/Alt；中间按任何其他键都会取消该组合。
- **完整窗口的 X：** 退出程序并保存数据。如果想让它继续运行，请用快捷键而不是 X。迷你窗口没有 X。
- **窗口按钮：**
  - **"Data folder"**（数据文件夹）：在资源管理器中打开 `C:\Program Files\Time`。
  - **"Categories"**（分类）：在记事本中打开 `categorias.txt`。
  - **"Start with Windows"**（开机自动启动）：开启/关闭开机自动启动。
  - **"Phone access"**（手机访问）：开启局域网仪表盘并显示可复制的链接（见[手机仪表盘](#手机仪表盘)）。
- **再次打开 `Time.exe`**（双击）不会创建第二个副本：它只会显示已在运行的程序的迷你窗口。这是某台电脑上快捷键失效时的备用方法。

## 手机仪表盘

Time 可以在手机浏览器中显示同样的数据。它不使用云端，不需要账号，也不向外部发送任何数据：由程序本身在局域网内提供网页。

### 如何开启

1. 打开窗口（快捷键），勾选 **"Phone access (local network)"**（手机访问，局域网）。
2. 首次开启时，Windows 会请求权限（UAC）以在防火墙中开放端口（仪表盘端口和电脑发现端口）。请允许——只需这一次。
3. 点击 **"Copy"**（复制）按钮复制链接。链接格式如下：`http://192.168.0.10:8787/?k=ABCD-EFGH`（IP 和访问码为你电脑的实际值）。
4. 在**同一 Wi-Fi 网络**下用手机打开该链接。
5. 在手机上使用 **"添加到主屏幕"**，即可像应用一样使用。

在电脑本机上，同一个仪表盘可以通过 `http://localhost:8787/?k=你的访问码` 打开。

链接末尾的 `?k=...` 就是**访问码**。没有访问码的人打开地址只会看到输入访问码的界面；只有输入正确的访问码才会显示数据。

### 显示内容

- **"Today"**（今天）：今日时长和时间段（首次和最后活动）。
- **"Per PC"**（按电脑）：每台电脑今天的使用时长以及是否在线。点击某台电脑即可只查看它正在使用的内容。
- **"By group"**（按分组）：按 `categorias.txt` 的分组汇总今日时长（只有设置了分组时才显示）。
- **"Per app"**（按程序）：今天使用最多的程序，每个程序都有一条与时长成比例的细进度条。点击某个程序可打开它的**详情**：今日时长、最近 14 天图表、本周、本月，以及使用过它的日子。
- **"By hour"**（按小时）：24 根柱子，每小时一根，使用最多的小时会高亮显示。打开往日记录时也会显示。
- **"Last 14 days"**（最近 14 天）：折线图并显示这段时间的平均值。线条在底部为绿色，越高越变为琥珀色和红色：当天时长越高，颜色越暖。
- **"This week"**（本周）和 **"This month"**（本月）：从周一和本月 1 日起的总时长，以及有使用的日子的日均时长，并与上周、上月的同一时段比较（例如 "▲ 12% vs last week"）。
- **"Previous days"**（往日记录）：图表下方显示每一天的摘要（只有日期和总时长）。点击某一天，会打开标出该日的图表，并列出当天使用的所有程序；**"← Back"**（返回）回到今天。
- **"Report"**（报告）：**"Days"**、**"Apps"** 和 **"Hours"** 按钮可以把历史记录下载为 CSV 表格（可用 Excel 打开）。在所有电脑的汇总视图中包含列表里的每台电脑；在单台电脑的视图中只包含那台电脑。
- **"Add or remove PCs"**（添加或移除电脑），位于页面底部，用于加入其他电脑。
- **"On the network now"**（当前网络中）：同一网络中正在运行的其他 Time，可直接添加。
- 每 30 秒自动刷新一次。

界面无圆角，便于在手机上快速阅读。它会跟随手机的主题（浅色或深色）；顶部的 ☀/☾ 按钮可以切换主题，选择会保存在该设备上。窗口隐藏时仪表盘仍可使用——只需要电脑开机并且 Time 正在运行。

### 多台电脑

每台电脑各自运行 Time。如果想在**同一个链接**中查看所有电脑，请选一台作为主机（开机时间最长的那台）。

在其他电脑上重复上述安装步骤即可（同一个 `Time.exe` 适用于所有电脑），并在其窗口中勾选 **"Phone access (local network)"**——这样主机才能读取它的数据。`pcs.txt` 只存在于主机上。

**仪表盘会自动发现其他电脑。** 在主机上（通过 `localhost` 或手机）打开页面底部的 **"Add or remove PCs"**。同一网络中正在运行的 Time 会出现在 **"On the network now"** 下，旁边显示 IP：

```
ON THE NETWORK NOW
DESKTOP-NOTE                      192.168.0.51
[ other PC's code ]                     [ ADD ]
```

名称默认填入电脑名，你可以在添加前改成 "笔记本"、"办公室" 等。输入那台电脑的**访问码**（即其窗口中显示的链接里的 `?k=`），然后点击 **"Add"**（添加）：只需一次，仪表盘会先在网络中确认访问码正确后再接受。

也可以通过链接添加：在下方的输入框中粘贴另一台电脑的完整链接（`http://192.168.0.51:8787/?k=IJKL-MNOP`）并填写名称，然后点击 **"Add"**。立即生效，无需重启。每个名称旁边的 **×** 可将该电脑从列表中移除。

**IP 变化时，仪表盘会自动调整。** 每个 Time 每 10 秒在网络中广播一次（不发送你的任何数据：只有电脑名和端口）。主机收到广播后会立即更新该电脑的地址，但会先确认回应者持有访问码——没有人能冒充其他电脑。`pcs.txt` 中保存的 IP 只是备用，用于网络不允许广播通过的情况。

数据文件夹中的 `pcs.txt` 每行保存一台电脑：

```
nome; codigo; maquina; ip:porta
Notebook; IJKL-MNOP; DESKTOP-NOTE; 192.168.0.51:8787
```

（名称；访问码；电脑名；ip:端口。）可以手动编辑，但没有必要：通过网页添加的内容会自动保存到这里。

主机的仪表盘会汇总所有电脑的时长，并显示 **"Per PC"** 列表。关机的电脑显示为 `offline`，不计入总数。所有电脑需要在同一网络中，并且都已开启仪表盘——每台电脑首次开启时，Windows 都会请求开放防火墙（与开启仪表盘时相同的 UAC）：会同时开放仪表盘端口和发现端口。

### 只查看一台电脑

点击 **"Per PC"** 列表中的任意电脑（行末有一个 `›` 箭头）。仪表盘随后只显示这台电脑：

- 今日时长及时间段（首次和最后活动）；
- 它当前正在使用的程序，显示在顶部（`Counting · VS Code`——正在计时 · VS Code）；
- 它使用的程序及各自时长；
- 这台电脑最近 14 天的图表。

**"← All PCs"**（所有电脑）返回汇总视图。地址末尾会带有 `&pc=...`，因此刷新页面仍会停留在同一台电脑。关机的电脑无法打开——它在列表中显示为 `offline`，仪表盘无法查询它的使用情况。

### `config.txt`

| 键 | 说明 |
|---|---|
| `porta` | 仪表盘端口（默认 `8787`）。 |
| `codigo` | 仪表盘密码。修改后，已配对的手机将无法再访问。 |
| `api` | `1` = 程序启动时开启仪表盘；`0` = 关闭。 |
| `firewall` | Windows 已开放的端口（`0` = 无）。 |
| `firewalludp` | Windows 已开放的网络发现端口（`0` = 无）。 |

编辑文件后，**关闭并重新打开 Time** 才会生效。

### 手机无法打开时

- 确认手机与电脑在**同一网络**中。
- 如果 Windows 提示"允许 Time 通信……"，请点击**允许**。取消该提示会为 `Time.exe` 创建一条**阻止**规则——阻止规则优先于允许规则，所以即使端口已开放，手机仍无法访问。检查方法：**高级安全 Windows Defender 防火墙** → **入站规则** → 删除所有名称为 `Time.exe` 的阻止规则。
- Time 会自动创建三条规则：按端口（TCP 8787 和 UDP 8788）和按程序。按程序的规则可以避免出现上述 Windows 提示。
- Windows 网络设置为**专用**或**公用**均可：规则在两种情况下都有效。
- 确认电脑已开机，并且 Time 正在运行。
- 地址是 **HTTP** 而不是 HTTPS——浏览器不显示锁形图标是正常的。
- 如果 **"On the network now"** 中没有显示另一台电脑，请检查它的仪表盘是否已开启、Windows 网络是否设置为**专用**，以及是否已在该电脑上开放防火墙（在该电脑上打开一次窗口并允许 UAC）。

### 安全

仪表盘适用于家庭或办公室网络。访问码可以保护数据，但传输内容没有加密（没有 TLS）。**不要把这个端口开放到互联网。** 如果想从外部查看，请使用 Tailscale 或 ZeroTier 等 VPN：同一地址即可通过 VPN IP 访问，而不会暴露任何内容。

网络发现同样不会发送访问码，哪怕是哈希值也不会：广播只包含电脑名和端口。当某台电脑的地址变化时，仪表盘会通过 HMAC 质询确认其身份——没有访问码，任何人都无法冒充那台电脑。

## 限制

- `GetLastInputInfo` 只能检测当前的交互会话；它不是覆盖所有 Windows 会话的全局服务。
- 程序无法知道视频是在播放还是已暂停。暂停在最前面的视频会一直计时，直到该项目的容忍时间用完。
- 从程序启动那一刻开始计时；无法补回启动之前的时间。
- 快捷键依赖 Windows 把键盘输入传给程序（键盘钩子）。如果电脑上的某些安全策略阻止了这一点，快捷键将无法使用；这时请再次打开 `Time.exe` 来显示窗口。
- 写入 `C:\Program Files` 需要管理员权限。首次运行时，程序会请求一次 UAC 来开放该文件夹；如果被拒绝，会改用 `%LocalAppData%\Time`，并在窗口中提示。
- 如果没有管理员限制，任何人都可以通过 X 或任务管理器关闭程序。这种情况下，当天的数据将不完整。
- 手机仪表盘只有在电脑开机、Time 正在运行、手机在同一网络中时才能使用。它是普通 HTTP（无 TLS），因此不应暴露到互联网。
- 按程序统计的数据依赖 Windows 报告哪个窗口在最前面。在后面打开的程序或非活动的标签页不计时。
- 电脑发现功能使用局域网广播。阻止广播的公司网络，或启用了客户端隔离的 Wi-Fi，会使电脑之间无法互相发现；这种情况下，请通过链接逐台添加。

## 隐私

Time 是为**个人使用**而设计的：统计你自己的电脑使用时间，帮助你保持专注。数据属于你，并保存在你自己的电脑上。

- 不记录按键，不截屏，不保存窗口标题。
- 手机仪表盘不会离开局域网，并且需要访问码。
- 文件保存在 `C:\Program Files\Time`。

如果要在他人或团队中使用，请**以书面形式**告知统计了什么（每个程序的使用时间）以及不统计什么（按键、截屏、内容）。在许多地方，秘密监控他人可能是违法的——例如在巴西，劳动法庭通常会将其视为非法证据，并可能判定精神损害赔偿。请把这些数据当作日常参考，而不是绩效评分：坐在电脑前的时间不等于工作效率——会议、电话和等待渲染都不会显示为活动。

低调运行，不打扰使用者——在他人电脑上使用时，请事先与使用者达成一致。
